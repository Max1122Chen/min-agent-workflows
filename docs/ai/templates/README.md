# Templates Index

Use these templates to keep collaboration artifacts consistent and machine-readable.

- `DOC_GOVERNANCE.md` - workflow and document governance source of truth (includes ALL-CAPS naming + domain bucketing)
- `WORKFLOW_PRESETS.md` - meta-question, named presets, dimension→effect map
- `design-spec.template.md` - what to build and why → save as `docs/ai/<DOMAIN>/<FEATURE_ID>_<SLUG>_DESIGN.md`
- `implementation-plan.template.md` - how to slice implementation → `..._IMPLEMENTATION.md`
- `roadmap.template.md` - milestone sequencing and scope → `..._ROADMAP.md`
- `adr.template.md` - architecture decisions → `docs/ai/<DOMAIN>/ADR-<yyyyMMdd>-<nn>_<SLUG>.md`
- `bug-record.template.md` - defects and regression checks → `BUG-<DOMAIN>-<nnn>_<SLUG>.md`
- `progress-log-entry.template.md` - append format for progress log
- `session-note.template.md` - handoff and context recovery
