# Templates Index

Use these templates to keep collaboration artifacts consistent and machine-readable.

- `DOC_GOVERNANCE.md` - workflow and document governance source of truth
- `WORKFLOW_PRESETS.md` - meta-question, named presets, dimension→effect map
- `design-spec.template.md` - what to build and why
- `implementation-plan.template.md` - how to slice implementation
- `roadmap.template.md` - milestone sequencing and scope
- `adr.template.md` - architecture decisions
- `bug-record.template.md` - defects and regression checks
- `progress-log-entry.template.md` - append format for progress log
- `session-note.template.md` - handoff and context recovery
